# HTML Wireframe Project

This is a personal portfolio website created using **HTML and CSS**.

## 📌 Project Overview

This project is a simple **HTML Wireframe Portfolio Project**.  
It contains different sections to display personal information, skills, projects, education, certified courses, and contact details.

## 🚀 Features

- 🏠 Home section
- 👤 About Me section
- 💻 Skills section
- 📂 Projects section
- 🎓 Education section
- 📜 Certified Courses section
- 📞 Contact Us section
- 🔗 GitHub and LinkedIn information
- 📱 Basic portfolio layout
- 🎨 CSS styling
- ⭐ Font Awesome icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
